Cherry Blossom — approved Petal direction

The five supplied colors are used unchanged for the supported Fusion skin surfaces and accents. Existing native dark foregrounds are referenced for text readability; semantic warning/error, node category, socket and cache/render colors remain intact. No new plum, gray or derived theme shades are introduced.

Apply Theme, Start Resolve and Restore Original require Resolve closed normally. Apply installs the Fusion skin and starts a new themed session; Start Resolve starts later themed sessions. Windows may identify the Fusion administrator helper as Python. Existing sessions are never closed or restarted automatically; neither application is minimized. Original backup, exact build/hash checks, finite helper deadline and atomic transaction journal remain in place.

The persistent Fusion layer modifies Fusion.skin and Neutral.skin inside Fusion.fuskin. All 7199 other archive entries are unchanged. Fusion appearance was confirmed by the user. The separate application layer changes 20 color properties in four main Qt stylesheet slots, only inside a fresh process started by Omen. Its recipe and exact original/proposed resources are in Application. The installed executable, regular shortcuts, fonts, icons, geometry and non-color declarations stay unchanged.

Application scope: exposed page-bar frame, standard menu bar/text/selected titles, text tooltips, enabled scrollbar handles, Sound Library keyword field and Inspector subtitle caption timecode field. Popup menus, most panels, custom drawing, Fairlight DLL resources, plug-ins, video and data retain native appearance. The expanded test is not a complete theme and still requires live startup/readability/behavior checks. The approved visual is a concept, not an expanded Resolve capture. Clip palettes and Veil's appearance modes remain independent.

After closing a themed session, the regular shortcut uses original main application colors; Fusion remains themed until Restore Original. Startup timeout preserves the resumed process. Explicit Clear stalled startup recovery is allowed only after confirmation that no Resolve window or loading project exists; it rechecks the exact failed process identity. A restricted Codex diagnostic account cannot launch Resolve.

Oxygen Test is no longer an available theme. Known previous skin hashes are recognized solely to allow restoration before applying Cherry Blossom. Historical original backups are retained for recovery; they are not themes in the catalogue.
